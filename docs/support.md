# Support

Parity Scrollr supports current stable Chrome and Microsoft Edge on desktop.

When reporting a problem, include:

- Browser name and version
- Parity Scrollr version
- Whether Compatibility mode was enabled
- The action that failed and the exact visible error
- Sanitized example URLs with private preview, authentication, and signed-link tokens removed
- Whether each page works when opened directly

Do not submit account credentials, cookies, private tokens, or confidential captures.

Support is available through the [Parity Scrollr issue tracker](https://github.com/kylbutlr/parity-scrollr/issues). For installation and manual updates, see [INSTALL.md](../INSTALL.md).
