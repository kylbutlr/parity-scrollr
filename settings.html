Parity Scrollr

Settings

By default, Parity Scrollr asks for access only to the two sites you compare. Classic workflow keeps site access available so repeat comparisons need fewer prompts.

Classic workflow

Keeps the previous low-friction experience: access to all websites stays available, Compatibility mode starts on, URL details are mirrored, implementation URLs are remembered, and the Shopify profile is selected. Chrome describes this permission as the ability to read and change data on all websites.

Your data

Active comparison URLs are temporary. Preferences and an optional implementation URL can be saved in this browser. Captures download to your device and are not uploaded by Parity Scrollr. Compared pages still contact their own services normally.
