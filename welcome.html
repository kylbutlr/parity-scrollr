Parity Scrollr

See the difference, side by side

Compare a website or design image with your implementation. Match viewport sizes, scroll together, and save a visual record of your review.

Start your first comparison

  1. Open a website and click the Parity Scrollr toolbar icon.
  2. Choose Website to compare two pages, or Design image to import a PNG or JPEG export. For images, enter the design frame width in CSS pixels.
  3. Enter the implementation URL. If a page does not load, Parity Scrollr automatically tries Compatibility mode once.
  4. Review the exact sites and why access is needed, then continue to Chrome's permission prompt. By default, that access is removed when the comparison ends.
  5. Scroll either page, choose a viewport size, or download a comparison capture.

Automatic page recovery

Some sites block side-by-side viewing. If a page does not report ready within 15 seconds, Parity Scrollr retries once with Compatibility mode. This temporarily disables some page protections for the selected sites in that tab. This can change which scripts and resources the pages load. Sign-in and bot checks may still prevent loading. Learn about unsupported pages.

Your comparison stays local

Parity Scrollr keeps active URLs in this browser session and downloads captures directly to your device. It does not upload captures or send comparison data to the extension developer. The pages you compare still contact their own services normally. Read the privacy details.

Capture needs one confirmation

If a capture button is disabled, click the Parity Scrollr toolbar icon while the comparison tab is active. Capture access lasts only for that comparison tab unless you enable persistent all-site access.

Ready to begin? Open a website, then click the Parity Scrollr toolbar icon. Pin it in your browser's Extensions menu for easy access.
