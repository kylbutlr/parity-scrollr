Parity Scrollr

Compare two pages, side by side

Parity Scrollr compares a reference page and an implementation page in one browser tab. It runs only when you start a comparison.

Start your first comparison

  1. Open the reference page and click the Parity Scrollr toolbar icon.
  2. Enter the implementation page. Leave Compatibility mode off unless a page will not load.
  3. Review the exact sites and why access is needed, then continue to Chrome's permission prompt. By default, that access is removed when the comparison ends.
  4. Scroll either page, choose a viewport size, or download a comparison capture.

Use Compatibility mode only when needed

Some sites do not allow their pages to appear inside another page. Compatibility mode temporarily relaxes that framing protection for the two selected sites in the comparison tab. It cannot bypass sign-in, bot checks, or other security controls. Learn about unsupported pages.

Your comparison stays local

Parity Scrollr keeps active URLs in this browser session and downloads captures directly to your device. It does not upload captures or send comparison data to the extension developer. The pages you compare still contact their own services normally. Read the privacy details.

Capture needs one confirmation

If a capture button is disabled, click the Parity Scrollr toolbar icon while the comparison tab is active. Capture access lasts only for that comparison tab unless you enable Classic workflow.
