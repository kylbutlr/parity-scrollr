Parity Scrollr

Compare two pages, side by side

Parity Scrollr is a focused browser extension for visual comparison and responsive frontend QA. It runs only when you start a comparison.

Start your first comparison

  1. Open the reference page and click the Parity Scrollr toolbar icon.
  2. Enter the implementation page and choose whether Compatibility mode or a Shopify profile is needed.
  3. Approve access to the selected site origins. The safer default removes that access when the comparison ends.
  4. Use synchronized scrolling, responsive sizes, URL parity, Blink mode, and capture in the comparison tab.

Compatibility mode changes page protections

Some sites block framing. Compatibility mode removes enforced Content Security Policy and X-Frame-Options response headers only for the two approved origins, only for subframes, and only in the active comparison tab. It cannot bypass authentication, anti-bot checks, JavaScript frame busting, or other site security controls.

Capture needs one extra confirmation

With safer per-site access, click the toolbar icon while the comparison tab is active to enable visible and full-page capture for that tab. Classic workflow users with persistent all-site access do not need this extra click.
